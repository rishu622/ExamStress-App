# ExamStress

ExamStress is an AI-assisted student wellbeing platform designed to help schools identify early signs of exam stress and connect students with timely support.

## Features

- Counselor dashboard with wellbeing risk zones and real-time alerts
- VoiceSense analysis of vocal energy, pitch, speech rate, pauses, and related indicators
- Student portal with wellbeing trends and supportive recommendations
- Anonymous, moderated peer-support chat
- Attendance voice-analysis simulator for demonstrations
- Role-based demo portals for counselors, administrators, peer mentors, and students

> Voice-based indicators are decision-support signals, not medical diagnoses. Counselor judgment and appropriate safeguarding processes remain essential.

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Available scripts

- `npm run dev` - start the development server
- `npm run build` - run TypeScript checks and create a production build
- `npm run lint` - run Oxlint
- `npm run preview` - preview the production build locally

## Tech stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, Recharts, and Lucide React.
